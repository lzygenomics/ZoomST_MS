\section{Discussion and conclusion}

ZoomST treats relationships between observation granularities as a
learnable component of spatial transcriptomic pretraining.
Molecular--spatial learning retains tissue descriptions within each
granularity, while nested-neighborhood supervision links these
descriptions through soft distributional equivariance.
In mouse and human developmental atlases, frozen representations
support anatomical transfer, while cross-granularity supervision
enriches developmental information.

Importantly, linking granularities does not make their descriptions
interchangeable: fine and coarse context retain distinct anatomical uses.
This motivates querying how a location's description changes with
observation range.
On held-out mouse sections, the learned transformations predict
representations at unseen intermediate granularities and support
comparisons of relative context sensitivity.
Anatomical analyses relate these responses to both composition changes
and molecular-context variation within an anatomical compartment.
ZoomST thus makes observation granularity both a source of
self-supervision and an axis for analyzing spatial context dependence.
